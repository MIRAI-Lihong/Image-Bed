# 安全与部署基线检查表

本文档用于记录当前版本需要人工确认的安全和部署检查点。

## 1. 环境变量

上线前需要确认：

- 阿里云长期密钥仅配置在 Netlify 环境变量中
- 仓库中不存在真实 `AccessKey` / `Secret`
- 前端 `VITE_*` 变量中不包含任何长期密钥
- `.env.example` 仅包含变量名和示例值

## 2. STS 临时授权

需要确认：

- 前端只能调用 Netlify Function 获取临时凭证
- 凭证有效期控制在 5 到 15 分钟
- 权限仅覆盖指定 Bucket 和指定对象前缀
- 首版不授予删除对象权限

## 3. OSS Bucket

需要确认：

- Bucket 保持公共读、非公共写
- 匿名用户不能直接写入对象
- 上传对象路径具备明确前缀约束
- 图片链接符合可长期访问的预期

## 4. OSS CORS

需要确认：

- 只允许实际使用到的来源域名
- 只放开必需的 HTTP 方法和请求头
- 不使用无边界的全开放配置
- 本地开发地址和 Netlify 域名都经过验证

## 5. Netlify Functions

需要确认：

- 函数内部读取的是服务端环境变量，而不是前端变量
- 环境变量缺失时会显式报错，不静默降级
- 不通过函数中转图片文件本体
- 函数日志不输出敏感凭证

## 6. 危险操作

默认不自动执行以下动作，除非用户明确确认：

- 修改生产环境变量
- 调整 Bucket 权限策略
- 放宽 CORS
- 删除 OSS 对象
- 执行部署或推送

## 7. 发布前最小检查

- 本地类型检查通过
- 本地 Lint 通过
- 本地测试通过
- 本地构建通过
- 关键安全边界已复核
